# 絵しりとり

絵を描いて、前の人の絵を当てて、最後の文字から次の絵を描く。2〜8人で遊べるオンラインの絵しりとりです。

**遊ぶ:** https://kawai-mdgc.github.io/e-dengon/shiritori.html

## 遊び方
1. ホストが部屋をつくり、コードか招待リンクを共有する
2. 全員そろったらホストが開始(順番はランダム)
3. 1番目の人だけにお題が出る。絵を描いて完成を押す
4. 次の人は前の絵だけを見て、何の絵かを答え、その最後の文字から始まる言葉を絵に描く
5. 終わったら、答えが合っていたかを一気に見る

## しくみと注意
- サーバーは使わず、ブラウザ同士を直接つないで遊びます(WebRTC / [PeerJS](https://peerjs.com/))。接続の仲立ちにPeerJSの公開ブローカーを使います。
- 部屋をつくった人(ホスト)のブラウザがゲームのデータを持ちます。ホストがタブを閉じると部屋は終わります。
- 会社や学校のネットワークなど、厳しい環境では接続できないことがあります。
