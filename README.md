# お絵描き伝言ゲーム

お題 → 絵 → 文章 → 絵 … と回して、最後に変化を一気に見るオンラインのお絵描き伝言ゲームです(2〜10人)。

**遊ぶ:** https://kawai-mdgc.github.io/e-dengon/

## 遊び方
1. 1人が「部屋をつくる」を押し、表示された4文字の部屋コードを友だちに伝える(ページのURLを送ってもOK)
2. 友だちはコードを入力して参加する
3. 全員がお題を文章で書く
4. 隣の人のお題を絵に描き、回ってきた絵を文章にする。これを交互に繰り返す
5. 全員が全部のお題に触れたら結果発表

## しくみと注意
- サーバーは使わず、ブラウザ同士を直接つないで遊びます(WebRTC / [PeerJS](https://peerjs.com/))。接続の仲立ちにPeerJSの公開ブローカーを使います。
- **部屋をつくった人(ホスト)のブラウザがゲームのデータを持ちます。** ホストがタブを閉じると部屋は終わります。ホストが同じブラウザで開き直すと、途中から復元されます。
- 会社や学校のネットワークなど、厳しい環境では接続できないことがあります。
- ビルド不要の単一ファイル(`index.html`)です。
