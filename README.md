# お絵描き伝言ゲーム

お題 → 絵 → 文章 → 絵 … と回して、最後に変化を一気に見るオンラインのお絵描き伝言ゲームです(2〜10人)。

## 遊び方
1. 部屋をつくり、4文字の部屋コードを友だちに伝える
2. 全員がお題を文章で書く
3. 隣の人のお題を絵に描き、回ってきた絵を文章にする。これを交互に繰り返す
4. 全員が全部のお題に触れたら結果発表

## 動かすときの注意
`index.html` は単一ファイルですが、通信(部屋・参加者・作品の共有)に claude.ai の Artifact 用の共有データベース(`window.claude` の `db` / `user`)を使っています。
そのため、GitHub Pages などの外部ホスティングに置いただけでは部屋の作成や参加が動きません。
外部で遊べるようにするには、`db` 部分を Firebase などの別のバックエンドに置き換えてください。
